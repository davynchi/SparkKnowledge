# SparkKnowledge

**SparkKnowledge** — это интеллектуальное веб-приложение на Django с поддержкой
LLM, предназначенное для проведения викторин по различным учебным темам. Оно
использует мощь языковой модели (Mistral) для генерации заданий и оценки
ответов, предлагая пользователю динамичный и интерактивный опыт обучения.

## 🚀 Основные возможности

- Выбор темы, уровня сложности и типа задания (множественный выбор или числовой
  ответ)
- Автоматическая генерация заданий и обратной связи от LLM
- Поддержка LaTeX для математических выражений
- Таймер викторины
- История всех попыток и просмотр диалогов
- Эстетичный дизайн с адаптивной версткой
- Обработка ошибок сети и превышения лимита запросов

## 🧠 Используемые технологии

- Python 3.12
- Django 5.x
- Mistral LLM API
- Bootstrap 5
- MathJax (для отображения формул)
- Django templates
- pre-commit (pylint, black, isort, prettier)

## 📦 Установка

1. **Клонируй репозиторий**:
   ```bash
   git clone https://github.com/yourusername/sparkknowledge.git
   cd sparkknowledge
   ```
2. **Создай виртуальное окружение и активируй его**:

   ```bash
   conda create -n web_django python=3.12
   conda activate web_django
   ```

3. **Установи зависимости**:

   ```bash
   pip install -r requirements.txt
   ```

4. **Создай .env файл в корне проекта**:

   ```env
   SECRET_KEY=your_django_secret_key
   LLM_API_KEY=your_mistral_api_key
   ```

5. **Применить миграции**:

   ```bash
   python manage.py migrate
   ```

6. **Запустить локальный сервер**:
   ```bash
   python manage.py runserver
   ```

Теперь приложение будет доступно по адресу http://localhost:8000

## 🧪 Пример использования

Вводишь никнейм, тему (например, «математика»), уровень сложности и формат.

Устанавливаешь время викторины.

Начинается диалог с моделью — она формулирует задание.

Отвечаешь — модель даёт обратную связь и следующий вопрос.
